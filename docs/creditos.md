# Créditos e fontes

## Calendário litúrgico
- **Datas, graus e cores do Calendário Romano Geral**: projeto Liturgical
  Calendar API (github.com/Liturgical-Calendar/LiturgicalCalendarAPI),
  licença Apache 2.0. Os nomes em português foram reescritos no padrão
  brasileiro.
- **Calendário Próprio do Brasil**: lista publicada pela CNBB (3ª edição do
  Missal Romano).
- **Conferência**: o calendário calculado pelo app é comparado, dia a dia, com
  o calendário litúrgico do Brasil publicado para 2024 a 2027
  (`src/liturgia/gabarito/`, só grau e cor de cada dia).
